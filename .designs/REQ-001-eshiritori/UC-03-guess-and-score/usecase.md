# ユースケース定義: 当てて勝敗を決める

> 置き場: `.designs/REQ-001-eshiritori/UC-03-guess-and-score/usecase.md`
> **観客は業務側です。** 技術仕様（アーキテクチャ・DB 設計・クラス構成）はここに書かず、設計フェーズの成果物に書きます。

## 概要

### 目的

UC-02 で描かれた絵を見て、描き手以外のメンバーが画面から回答し、最初に当てた人が得点するようにする。ゲームの終わりには正解数で勝者を決める。

### スコープ

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | ゲーム中の、描き手以外のメンバー（当てる人）と、得点を見るメンバー全員 |
| 対象業務 | 回答する、正解が判定されて得点しターンが交代する、得点表を見る、結果画面で順位と勝者を見る |
| 対象外 | ターンの交代・お題・描画・パス・ゲームの終了と再戦そのもの（UC-02）、しりとりの規則（UC-04）、描き手への得点（REQ ヒアリング Q9） |

### 画面

| 画面名 | モック・参照先 | 補足 |
| --- | --- | --- |
| ゲーム画面（当てる人） | `../UC-02-draw/mockups/game.html` | UC-02 の画面に、回答の入力欄・回答の流れ・得点表を加える |
| 結果画面 | `../UC-02-draw/mockups/game.html` | UC-02 の画面に、正解数の順位と勝者を加える |

## 要件

### 要件 1: 当てる

**ユーザーストーリー:** 当てる人として、絵を見て思いついた言葉を何度でも答えたい。誰よりも早く当てて得点するためである。

#### 受け入れ基準

1. 描き手以外のメンバーがお題と一致しない回答を送ったとき(WHEN)、(THEN)システムは、その回答を回答者のニックネームと一緒にメンバー全員に表示すること(SHALL)
2. 描き手以外のメンバーがお題と一致する回答を送ったとき(WHEN)、(THEN)システムは、回答の文字は表示せずに「◯◯さんが正解」と全員に表示し、その人の正解数を 1 増やし、お題を全員に公開してターンを終えること(SHALL)
3. 回答とお題を比べるとき(WHEN)、(THEN)システムは、ひらがなとカタカナの違いを同じとみなすこと(SHALL)
4. 描き手がお題を確定するまでの間(WHILE)、(THEN)システムは、回答を受け付けないこと(SHALL)
5. 描き手の画面において(WHERE)、(THEN)システムは、回答の入力欄を表示しないこと(SHALL)

### 要件 2: 得点と勝敗

**ユーザーストーリー:** メンバーとして、誰が何回当てたかをいつでも見られ、最後に勝者を知りたい。競い合って楽しむためである。

#### 受け入れ基準

1. ゲームの間(WHILE)、(THEN)システムは、メンバー全員の正解数を全員に表示すること(SHALL)
2. ゲームが終わったとき(WHEN)、(THEN)システムは、結果画面に正解数の多い順に並べた順位と勝者を表示すること(SHALL)
3. 正解数が最も多いメンバーが複数いる場合(IF)、(THEN)システムは、その全員を同率 1 位の勝者として表示すること(SHALL)
4. 再戦で新しいゲームが始まったとき(WHEN)、(THEN)システムは、全員の正解数を 0 に戻すこと(SHALL)
5. 描き手がパスしたとき(WHEN)、(THEN)システムは、誰の正解数も増やさないこと(SHALL)

### 要件 3: エラー・境界条件

**ユーザーストーリー:** 当てる人として、受け付けられない回答をしたときに理由を知りたい。正しく入れ直すためである。

#### 受け入れ基準

1. 回答にひらがな・カタカナ・長音記号（ー）以外の文字が含まれる場合(IF)、(THEN)システムは、使えない文字がある旨を回答者にだけ表示し、回答を受け付けないこと(SHALL)
2. ターンが既に終わった後に回答が届いた場合(IF)、(THEN)システムは、その回答を受け付けず、正解数を増やさないこと(SHALL)

## 非機能要件

| 観点 | 要件 |
| --- | --- |
| 性能 | 回答・正解・得点の表示が、ほかのメンバーの画面に 1 秒以内に反映される（ローカル環境で、8 人の部屋で計測） |
| 認可・セキュリティ | 回答できるのは描き手以外のメンバーだけ。正解の判定はシステム側で行い、当てる人の画面にお題の文字を渡さない（UC-02 の認可と同じ） |
| データ量 | 回答の記録はターンが終われば保持しない。正解数はゲームが終わるまで保持する |
| 可用性 | UC-01 と同じ |
| 監査 | 記録しない |
