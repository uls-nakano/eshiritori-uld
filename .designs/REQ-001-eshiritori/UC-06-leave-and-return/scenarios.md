## 読み方

- シナリオ ID は `S-06-{連番}`。この ID はこのファイル内の対応表で使います（結合テスト名には入れず、テスト名は受け入れ基準 ID でつなぎます）
- 「対応する受け入れ基準」は `usecase.md` の要件番号です
