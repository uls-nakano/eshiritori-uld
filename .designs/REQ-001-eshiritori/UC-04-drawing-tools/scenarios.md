# 合格シナリオ集: 描画の道具を使い分ける

> 置き場: `.designs/REQ-001-eshiritori/UC-04-drawing-tools/scenarios.md`
> シナリオフェーズの**主産物**です。設計フェーズのシナリオ整合チェックの正解データになり、**結合テストにそのまま流用されます**。
> 結合テストになった時点で、生きた仕様はテストコード側に移り、このファイルはログになります。以後は書き換えません。

## 読み方

- シナリオ ID は `S-04-{連番}`。この ID はこのファイル内の対応表で使います（結合テスト名には入れず、テスト名は受け入れ基準 ID でつなぎます）
- 「対応する受け入れ基準」は `usecase.md` の要件番号です
- 共通の前提: たろう・はなこ・じろうの 3 人の部屋で、じろうが描き手としてお題を確定し、描いている

| --- | --- |
| 対応する受け入れ基準 | 要件 1-1、1-2 |
