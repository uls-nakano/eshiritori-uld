# 合格シナリオ集: 絵を描いてみんなに見せる

> 置き場: `.designs/REQ-001-eshiritori/UC-02-draw/scenarios.md`
> シナリオフェーズの**主産物**です。設計フェーズのシナリオ整合チェックの正解データになり、**結合テストにそのまま流用されます**。
> 結合テストになった時点で、生きた仕様はテストコード側に移り、このファイルはログになります。以後は書き換えません。

## 読み方

- シナリオ ID は `S-02-{連番}`。この ID はこのファイル内の対応表で使います（結合テスト名には入れず、テスト名は受け入れ基準 ID でつなぎます）
- 「対応する受け入れ基準」は `usecase.md` の要件番号です
- 共通の前提: たろう（部屋を作った人）・はなこ・じろうの 3 人がいる部屋で、周回数 1 周のゲームが始まり、描く順番は じろう → たろう → はなこ に決まった
- 回答・得点（UC-03）としりとりの規則（UC-04）は、このシナリオ集では考えない。ターンはパスで終わる
