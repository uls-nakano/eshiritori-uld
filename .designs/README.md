# .designs — 開発フローの記録

ここは**ログ資料**です。「そのとき何を聞き、何に合意したか」の記録であり、**後から書き換えません**。内容を変えたくなったら、新しいフローを流して新しい記録を作ります。

現在の姿を表す資料（ドメインモデル図・用語集・API 仕様・アーキテクチャ文書・ルール・テストコード）は生き資料であり、`docs/` `rules/` と実装のフォルダにあります。両者を混ぜないでください。

フォルダの構成・採番・凍結の条件・読んでよい範囲と、記録を書き起こすテンプレートは、規約 [rules/design-records](../rules/design-records/standard.md) にあります。**過去の REQ を仕様の根拠にしないでください。** 何がどう振る舞うか・何が合意済みかは生き資料とコードが決めます。

実装ループのイベントログの形式は [events/README.md](events/README.md) にあります。
