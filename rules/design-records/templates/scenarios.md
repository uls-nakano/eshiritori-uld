- シナリオ ID は `S-{UC番号}-{連番}`。この ID はこのファイル内の対応表で使います（結合テスト名には入れず、テスト名は受け入れ基準 ID でつなぎます。rules/acceptance-testing の「仕様トレーサビリティ」）

- 正常系だけでなく、**考えられる異常系**を必ず展開します。制約の漏れは変な例の方が人の目に刺さります
