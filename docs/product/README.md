# プロダクトの目的

このフォルダは、絵しりとりアプリケーションが**何のために存在するか**を表す生き資料です。常に現在の姿を表し、古くなったら直します。

- 目的・対象利用者・提供価値の定義をここに置きます（最初の要求のシナリオフェーズで `.designs/` のヒアリングを経て合意したものを、生き資料として書き起こす）
- 個々の振る舞い（受け入れ基準）は [docs/usecases/](../usecases/README.md)、複数のユースケースを貫く流れは [docs/journeys/](../journeys/README.md)、用語は [docs/domain/ubiquitous-language.md](../domain/ubiquitous-language.md) にあります
- 要求の経緯（何を聞き、何に合意したか）はログ資料 [.designs/](../../.designs/README.md) に残り、ここには書きません

## 現在の定義

### 目的

知り合い同士が Web ブラウザで同じ部屋に集まり、絵当てとしりとりを組み合わせたゲームを、アカウントを作らずにすぐ遊べるようにする。

### 対象利用者

- 知り合い同士で集まって遊ぶプレイヤー。スマートフォンでの利用を主とし、PC のブラウザでも遊べる
- ログインはしない。部屋ごとにニックネームを名乗って参加する

### 提供価値

- 部屋の URL か部屋コードを共有するだけで、2〜8 人がすぐ同じゲームに集まれる
- 描き手が順番に交代しながら絵を描き、ほかのメンバーが早押しで当てる。前のお題の末尾の文字から次のお題を始めるしりとりの規則で、お題がつながっていく
- 最後に正解数で勝者が決まり、同じメンバーで続けて再戦できる

### 運用の前提

- 運用費をかけずに公開するため、AWS の無料枠に収まる構成で動かす。データの保存先は DynamoDB
- 遊び終わった部屋の記録は長期保存しない
- まずローカル環境で動作を確認し、その後クラウドへ載せる
