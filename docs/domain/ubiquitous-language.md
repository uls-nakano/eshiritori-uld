# ユビキタス言語

ドメイン用語の定義をここに集約します。境界ごとのモデル図のファイルには重複させません。

| 用語 | 識別子 | 定義 |
| --- | --- | --- |
| 部屋 | `Room` | プレイヤーが集まってゲームを遊ぶ単位。部屋コードで指し、最大 8 人のメンバーを持つ |
| 部屋コード | `RoomCode` | 部屋を指す英数字 6 文字のコード。口頭や招待 URL で共有する |
| 招待 URL | — | 部屋コードを含み、開くと部屋コードが入力済みの参加画面を表示する URL |
| メンバー | `Member` | 部屋に入ったプレイヤー 1 人 |
| ホスト | `Room.hostPlayerId` | 部屋を作った人。ゲームを始められるのはホストだけ |
| プレイヤー識別子 | `PlayerId` | メンバーを指す、全員に公開してよい識別子 |
| プレイヤートークン | `PlayerToken` | メンバー本人だけが持つ秘密の値。本人確認に使う |
| ニックネーム | `Nickname` | 部屋の中でプレイヤーが名乗る名前。前後の空白を除いて 1〜10 文字 |
| 周回数 | `RoundCount` | 全員が描き手を務める回数。1〜5 |
| 待機室 | — | 部屋が作られてからゲームが始まるまでの間、メンバーが集まって待つ画面 |
| 描く順番 | `Room.members` の並び | ゲームの開始時にランダムに決める、描き手を務めるメンバーの順。部屋のメンバーの並びで表す |
| 部屋の進行状態 | `RoomStatus` | 部屋が待機中か、ゲームが一度でも始まったか |
| 期限切れ | `Room.isExpiredAt` | 最後の更新から 24 時間たった部屋の状態。存在しない部屋として扱う |
| 改訂番号 | `Revision` | 部屋が保存された回数。同時の更新を先着順に裁く条件に使う |
