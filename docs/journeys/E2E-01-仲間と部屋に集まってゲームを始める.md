# E2E-01 仲間と部屋に集まってゲームを始める

## 概要

| 項目 | 内容 |
| --- | --- |
| アクター | 部屋を作る人（ホスト）、誘われた人 |
| ゴール | 別々の端末にいる仲間が同じ部屋に集まり、同じ描く順番でゲームを始める |
| 通るユースケース | [UC-01 部屋を作って仲間を招く](../usecases/UC-01-部屋を作って仲間を招く.md) → [UC-02 招待された部屋に入る](../usecases/UC-02-招待された部屋に入る.md) → [UC-03 ゲームを始める](../usecases/UC-03-ゲームを始める.md) |
| 確かめること | 部屋を作ってから全員の画面がゲーム画面に切り替わるまでが、本物の画面と API を通して途切れずにつながること |

## ケース

### 招待 URL で 1 人を誘って始める

たろうは、はなこと絵しりとりを遊ぼうと思い、トップ画面でニックネーム「たろう」を入れて部屋を作る。待機室には部屋コードと招待 URL が表示され、メンバー一覧には自分だけがホストとして並んでいる。

たろうが招待 URL をはなこに送る。はなこが別の端末でその URL を開くと、部屋コードが入った参加画面が出るので、ニックネーム「はなこ」を入れて部屋に入る。はなこの画面は待機室になり、たろうの待機室のメンバー一覧にも、画面を開き直すことなく「はなこ」が加わる。

2 人がそろったので、たろうが開始を押す。たろうとはなこの画面は、どちらもゲーム画面に切り替わり、同じ並びの描く順番が表示される。

**E2E-01-01**（未実装）: 部屋を作り、招待 URL で誘った仲間が入り、ホストが始めると、全員の画面が同じ描く順番のゲーム画面になる
