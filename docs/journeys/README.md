# ジャーニー

複数のユースケースを貫くジャーニーを、ストーリーとして表す生き資料です。E2E テストが、本物の画面と API を通してこのジャーニーが途切れずに成り立つことを確かめます。

- 受け入れ基準は定義しません。個々の振る舞いの基準は [docs/usecases/](../usecases/README.md) のユースケース記述が持ち、結合テストと UI の story が検証します
- 1 つのジャーニー（`E2E-01`、1 ファイル）は 1 本以上のケース（`E2E-01-01`）を持ちます。ケース ID が E2E テストとのトレースの結合キーです。ジャーニーの中で筋が置き換わるときは新しいケース番号で書き、元のケースは欠番として残します
- ケース ID の直後の状態マークは、「（未実装）」が設計フェーズで合意済みで E2E テストがまだのケース、「（廃止予定）」が置き換え先の実装を待っているケース、「（廃止）」が退役して欠番として残したケースです
- ID の運用は [rules/acceptance-testing](../../rules/acceptance-testing/standard.md) の「E2E テスト」を参照してください
